## 📌 Sobre o Projeto

O **PITWALL** é um projeto de desenvolvimento web criado como atividade prática de HTML5 e CSS3, com o objetivo de reproduzir uma página temática do Grande Prêmio de São Paulo, realizado no Autódromo de Interlagos.

A proposta consiste em desenvolver uma interface moderna, inspirada nos sites profissionais do automobilismo, apresentando informações sobre pilotos, classificação da corrida e venda de ingressos.

O projeto foi desenvolvido com foco na organização do código, identidade visual, experiência do usuário e adaptação para diferentes tamanhos de tela.

## 🎯 Objetivos

- Aplicar os conhecimentos adquiridos em HTML5 e CSS3.
- Desenvolver uma página web com estrutura semântica.
- Trabalhar com layouts utilizando Flexbox e CSS Grid.
- Criar uma identidade visual inspirada no automobilismo.
- Implementar responsividade para computadores e dispositivos móveis.
- Organizar formulários e tabelas utilizando HTML.
- Trabalhar com imagens, tipografia e paletas de cores.

## ⚙️ Funcionalidades e Seções

### 1. Página Inicial

- Cabeçalho com identidade visual PITWALL.
- Menu de navegação entre as seções.
- Banner principal do GP de São Paulo.
- Imagem temática do automobilismo.
- Estatísticas da corrida, incluindo voltas, distância e curvas.
- Botões de navegação para classificação e ingressos.

### 2. Grid de Pilotos

Apresentação de quatro pilotos, com cards individuais e identificação de suas respectivas equipes:

- Charles Leclerc — Ferrari.
- Oscar Piastri — McLaren.
- George Russell — Mercedes.
- Gabriel Bortoleto — Audi.

Cada card possui numeração, nome, equipe e cores personalizadas.

### 3. Classificação

Tabela organizada para apresentar informações dos pilotos:

- Posição.
- Nome do piloto.
- Equipe.
- Vitórias.
- Diferença de pontos.
- Pontuação.

A seção também apresenta campos de busca e seleção de equipes para compor visualmente a área de filtros.

### 4. Ingressos

Área destinada à apresentação dos setores e valores dos ingressos:

- Arquibancada A — R$ 480.
- Setor da Reta — R$ 890.
- Box VIP — R$ 2.400.

Também foi desenvolvido um formulário contendo:

- Nome completo.
- E-mail.
- Escolha do setor.
- Data.
- Quantidade de ingressos.
- Perfil do Instagram.
- Envio de fotografia.
- Mensagem para o piloto.

### 5. Rodapé

O rodapé apresenta a identificação do projeto, sua finalidade acadêmica e o nome do desenvolvedor.

## 📱 Responsividade

O PITWALL foi desenvolvido para se adaptar a diferentes resoluções de tela.

Foram utilizadas Media Queries para ajustar os elementos conforme o dispositivo.

**Computadores:**
- Layout distribuído horizontalmente.
- Grid de pilotos em múltiplas colunas.
- Formulário e informações de ingressos lado a lado.

**Dispositivos móveis:**
- Menu adaptado.
- Banner reorganizado verticalmente.
- Cards distribuídos em duas colunas.
- Formulário em coluna única.
- Tabela com rolagem horizontal quando necessário.

## 🚀 Como Executar

Para visualizar o projeto em seu computador:

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se a imagem está dentro da pasta `img`.
4. Abra o arquivo `index.html`.
5. Execute utilizando a extensão Live Server ou diretamente pelo navegador.

Não é necessário instalar dependências ou configurar um servidor backend.

## 🔮 Melhorias Futuras

O projeto foi desenvolvido inicialmente com HTML5 e CSS3, mas possui possibilidades de expansão.

Entre as melhorias planejadas estão:

- Integração com JavaScript para tornar os filtros funcionais.

- Integração com banco de dados MySQL.
- Cadastro e gerenciamento de pilotos.
- Classificação dinâmica e atualizada.
- Sistema de reservas de ingressos.
- Armazenamento das informações dos usuários.
- Implementação de um sistema de autenticação.

Essas melhorias poderão transformar a página estática em uma aplicação web mais completa e interativa.
